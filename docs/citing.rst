Citing RodeOFlow
================

If you use RodeOFlow in your research, cite the specific software version or
release that you used. Include the repository URL and, where possible, the
release tag or commit so that the version can be identified:

`RodeOFlow on GitHub <https://github.com/BarnstedtLab/RodeOFlow>`_

When a RodeOFlow preprint or paper is available, cite that publication as well.
The author list and publication details will be added here once they are
finalized.
