Troubleshooting
===============

Import errors
-------------

Make sure you activated the Conda environment where RodeOFlow is installed.
For a local checkout, install it from the repository root:

.. code-block:: bash

   python -m pip install -e . --no-deps

If Python still cannot import RodeOFlow, check which package it is finding:

.. code-block:: bash

   python -c "import rodeoflow; print(rodeoflow.__file__)"

Sphinx is not installed
-----------------------

Install the documentation requirements into the active environment:

.. code-block:: bash

   python -m pip install -r docs/requirements.txt

CUDA optical flow
-----------------

The Farneback option requires an OpenCV build with CUDA support. A CUDA-enabled
PyTorch installation alone does not provide CUDA support in OpenCV. If your
OpenCV build does not support CUDA, use the DIS optical-flow option on the CPU.

No files found to analyze
-------------------------

Check that the directory passed to ``analyse_face`` or ``analyse_body``
contains the corresponding keypoint files generated by the pose-estimation
step. Also check that the selected video file extension and filename filter
match your input videos.
